# Knowledge store

Plain markdown that outlives any single session.

| Folder | Holds | Rule |
|---|---|---|
| `decisions/` | Why the project is the way it is | Never edit a superseded decision's prose — write a new one that supersedes it |
| `learnings/` | What surprised us, with evidence | One lesson per note; include how to verify it |
| `memory/` | Durable project facts | Keep short and current; delete what stops being true |
| `handoffs/` | End-of-session notes | goal · done · obstacle · next |

`sdlc memory prime` assembles the cold-start pack from these; `sdlc memory capture` writes
notes; `sdlc memory supersede <old> <new>` retires a decision without deleting it.
